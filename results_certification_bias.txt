ESTIMAND (Target of Inference):
--------------------------------
We estimate the failure rate of a uniform mixture over strata:

    p = (1/4) Σ_{k=1}^4 p_k

where:
- K = 4 strata
- p_k = per-stratum failure rate
- Uniform weights w_k = 1/K (equal-sized evaluation slices)

For this experiment:
- Strata: ['easy', 'medium', 'hard', 'nightmare']
- Per-stratum p: {'easy': 0.0, 'medium': 0.02, 'hard': 0.1, 'nightmare': 0.32}
- True mixture p: 0.1100

CRITICAL: Both naive and stratified sampling estimate the SAME p under
uniform target mixture. The difference is:
- Naive: Composition varies randomly → biased at early stopping times
- Stratified: Composition fixed at all n → unbiased at all stopping times

CERTIFICATION DECISION:
- Threshold τ = 0.1
- Rule: Certify "p ≤ τ" if upper_bound(p̂, n, α) ≤ τ
- True state: p = 0.1100 > τ = 0.1 → should NOT certify
- Harm: False certification (Type I error in safety context)
