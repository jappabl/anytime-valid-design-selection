KEY FINDINGS:
==========================================================================================

1. At n ≤ 200 (our experimental regime):
   - Intersection is +2.3% wider on average
   - Range: +1.5% to +3.0%

2. At n ≥ 500 with p ≤ 0.05 (large-sample low-p regime):
   - Intersection is -13.7% narrower on average
   - Variance adaptation begins to overcome overhead

3. α-splitting overhead:
   - Hoeffding(α/2) uses log(2/δ_α/2) = log(2/δ_α) + log(2)
   - Additive log(2) ≈ 0.69 increase in log term
   - For typical δ_n values (log ≈ 10-15), this is ~5-7% increase
   - Translates to ~2-3% width increase after sqrt

4. Bernstein range term:
   - (7/3) * log(2/δ_n) / (n-1) dominates at small n
   - Makes Bernstein worse than Hoeffding until n ≥ 500

5. CONCLUSION:
   - For n ≤ 200 (our experiments): intersection provides NO benefit
   - For n ≥ 500 with p ≤ 0.05: intersection can save 10-30% width
   - Our use case doesn't reach the beneficial regime
