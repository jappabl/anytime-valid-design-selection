### 3. **Composition Drift Bug** - Computed Over Full N_MAX
**Problem**: Composition drift was computed over all 200 samples, not just samples up to stopping time n_stop. This makes the "composition drift at τ" metric incorrect.

**Fix**:
- ✅ Changed sampling functions to return `stratum_sequence` (list tracking which stratum each sample came from) instead of cumulative `stratum_counts` (lines 102-146)
- ✅ Updated `run_single_replication()` to compute `stratum_counts_at_stop` using only `stratum_sequence[:n_stop]` (lines 201-204)
- ✅ Now correctly measures composition drift at the actual stopping point

### 4. **No Git Hash / Version Logging**

**Fix**:

## Coupling Issue Discussion

**Audit Finding**: "Coupling only partial: naive and stratified use different seeds (base + 0 vs base + 1), so randomness streams are not shared."

**Current Design**:
```python
base = BASE_SEED + model_offset + rep * 1000
seed = base + (0 if method == 'naive' else 1)
```

**Rationale**:
- This ensures *independent* randomness for naive vs stratified on the same replication
- Both methods see the "same" model (same p values) but draw different outcome sequences
- Paired comparison is by replication index, not by shared random outcomes

**Alternative (Stronger Coupling)**:
- Could pre-generate Bernoulli draws with a single seed per replication
- Apply both sampling policies (naive vs stratified) to same outcome sequence
- This would isolate policy effect from random variation

**Status**: Current coupling is acceptable for demonstrating practical impact, but stronger coupling would improve precision. Could be future work.

## What Remains Version-Dependent

Even with all fixes, these factors may cause minor variation:

1. **NumPy RNG algorithm**: Changes between numpy versions (1.x → 2.x had major changes)
2. **Dict iteration order**: Guaranteed in Python 3.7+ but implementation-dependent
3. **Floating-point arithmetic**: Minor differences across platforms (x86 vs ARM)

**Mitigation**:
- Pinned versions in requirements.txt
- Git hash logged to link results to exact code
- Checksum enables exact verification
